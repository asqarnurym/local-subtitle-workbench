# Протокол F1: граничная F1 с учётом пропущенных и лишних слов

Записан 23.11.2026 **до любых чисел** этого анализа, по просьбе автора. Повод — критика FA-Bench (Chu et al. 2026, `docs/paper/dg2027/literature/EVIDENCE_NEW_SOURCES.md`): MAE по сопоставленным словам не штрафует систему за пропущенные и вставленные слова, на Buckeye это занижает ошибку систем с распознаванием на 9–14 %. Код — `scripts/f1_analysis.py`, тесты — `tests/test_f1_analysis.py`, результаты — `reports/f1_20261123/`, отчёт — `docs/F1_RESULTS.md`.

## Общее

- **Модели не запускаются.** Только сохранённые предсказания frozen E1: `reports/buckeye` (20 тестовых дикторов, 999 клипов) и `reports/timit` (16 дикторов, 160 клипов). Все 9 режимов: B0_whisper, B1_whisper_ctc, B2_proposed, B2_const, B2_brqe, A1_ctc, A2_proposed, A2_const, A2_brqe.
- **Frozen-результаты и CLAIM не меняются.** Основная метрика статьи остаётся MAE (предрегистрирована). F1 — вторичный анализ чувствительности, добавленный после выхода FA-Bench; так он и подаётся. Тестовые дикторы Buckeye уже много раз использованы.
- **Все клипы входят.** Клип, на котором режим упал, даёт ноль гипотез и пропуск всех своих эталонных границ (правило FA-Bench).
- **Сопоставление слов** — как в frozen-метриках: `_align_token_sequences` (Needleman–Wunsch +2/−2/−1 по нормализованным словам).
- **Проверка корректности.** Acc@20 по сопоставленным словам, посчитанная этим кодом, должна совпасть с frozen `word_metrics.acc_20ms` до 0,01 п.п., а число сопоставленных слов — с `num_matched`. Иначе анализ останавливается.

## Определения

- **Границы.** У каждого слова две границы: начало и конец (как в MAE проекта, где начало и конец объединены). Эталон клипа даёт 2·N_ref границ, предсказание — 2·N_pred.
- **F1_edge@τ (основная).** Граница — попадание, если её слово сопоставлено с эталонным словом и |t_pred − t_ref| ≤ τ. Precision = попадания / (2·N_pred), recall = попадания / (2·N_ref), F1 = 2PR/(P+R). τ = 20 мс (основное), 50 мс (вторичное; FA-Bench сообщает его для трека 1).
- **F1_ctx@20 (строгая, ближе к FA-Bench).** Дополнительно к F1_edge соседнее слово по другую сторону границы тоже должно быть сопоставлено, причём с соседним словом: для начала — эталонное слово r−1 сопоставлено с предсказанным p−1, либо оба слова первые в своих последовательностях; для конца — симметрично (r+1 с p+1, либо оба последние). Паузы не моделируются как отдельные метки.
- **Отличия от FA-Bench** (указываются в статье): у FA-Bench граница между двумя смежными словами одна, а края высказывания — отдельные границы против тишины; у нас у каждого слова свои две границы, поэтому смежные слова дают две совпадающие границы. Разбиения дикторов, версии MFA и нормализация текста тоже разные. Сравнение с числами FA-Bench только качественное (порядок величины и порядок систем).
- **Агрегация.** Корпусная F1 — по сумме попаданий и знаменателей всех клипов (micro). Значение диктора — F1 по сумме его клипов. Интервал корпусной F1 — бутстреп по дикторам (2000 повторов, seed 42; пересчёт micro-F1 по выбранным дикторам).

## Вопросы и правила (до чисел)

1. **A против B.** На Buckeye сохраняется ли порядок A2_proposed > B2_proposed по F1_edge@20? Тест по дикторам.
2. **BRQE против константы.** Сохраняется ли вывод CLAIM-103 (B2_brqe и A2_brqe лучше константного сдвига на Buckeye) при F1_edge@20? Тесты B2_brqe − B2_const и A2_brqe − A2_const по дикторам.
3. **MFA против CTC.** A2_proposed против A1_ctc и B2_proposed против B1_whisper_ctc на Buckeye.
4. **Цена несопоставленных слов.** Для каждого режима: разница между frozen Acc@20 (по сопоставленным словам, в долях) и recall_edge@20. Описательно, без теста.

Тесты 1–3 (пять сравнений) — одна семья, поправка Холма; точный знаковый ранговый тест Уилкоксона по 20 дикторам (`exact_signed_rank`). TIMIT — описательно, с тестами тех же пяти пар отдельной семьёй.

**Как читать результат.** Если направление вопросов 1–3 совпадает с MAE, в статье пишется, что выводы устойчивы к выбору метрики. Если какое-то направление меняется или эффект теряет значимость, это указывается как ограничение рядом с соответствующим утверждением; frozen-числа не заменяются.
