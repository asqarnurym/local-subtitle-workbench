## 3. Ответы на вопросы протокола

1. **A против B.** Порядок A2 > B2 сохраняется: на Buckeye у всех 20 дикторов, корпусная разница по F1 больше, чем по Acc@20 по сопоставленным словам (0,086 против 0,021), потому что F1 штрафует пропущенные слова B.
2. **BRQE против константы.** Вывод CLAIM-103 устойчив к выбору метрики: на Buckeye BRQE лучше константы у всех 20 дикторов в обоих сценариях. На TIMIT, как и по MAE (CLAIM-104), значимого выигрыша нет; при допуске 50 мс BRQE на TIMIT даже немного хуже MFA (0,884 против 0,898 в B, 0,908 против 0,921 в A) — согласуется с отрицательным переносом на читаемую речь (CLAIM-104, CLAIM-113).
3. **MFA против CTC.** Сохраняется везде, разница около 0,31–0,37 F1.
4. **Цена несопоставленных слов.** В сценарии B на Buckeye recall@20 на 7,7–8,3 п.п. ниже Acc@20 по сопоставленным словам (B2: 0,690 → 0,613, относительно −11 %). Это того же порядка, что занижение ошибки на 9–14 %, которое FA-Bench нашёл для систем с распознаванием на Buckeye. В сценарии A цена 0,3 п.п.; на TIMIT в B — 1,6 п.п. (Whisper там ошибается меньше).

**Итог:** выводы по A/B, BRQE и MFA/CTC устойчивы к замене MAE по сопоставленным словам на граничную F1, которая штрафует пропуски и вставки. Ограничение FA-Bench к нашим выводам на Buckeye не применяется; числа B по сопоставленным словам при этом оптимистичны примерно на 11 %, и это надо сказать в статье.

## 4. Сравнение с FA-Bench (качественное)

FA-Bench, табл. 1, уровень слов, чистая речь, F1@20 (TIMIT / Buckeye): MFA с эталонным текстом 0,64 / 0,68; Qwen3-ASR → MFA 0,63 / 0,60; Whisper large-v3 (свои метки) 0,10 / 0,14; MMS-FA 0,28 / 0,23; TorchAudio 0,21 / 0,18; F1@50 для MFA 0,92 / 0,93.

Наши (TIMIT / Buckeye): A2 MFA 0,684 / 0,710; B2 Whisper → MFA 0,661 / 0,624; B0 Whisper 0,020 / 0,063; A1 CTC (torchaudio MMS_FA) 0,344 / 0,340; F1@50 A2 0,921 / 0,926.

- **Совпадает:** уровень MFA (0,64–0,71 при 20 мс, 0,92–0,93 при 50 мс), порядок систем (MFA > CTC > собственные метки Whisper), отставание «ASR → MFA» от эталонного текста на Buckeye и почти полное его отсутствие на TIMIT.
- **Отличается:** наши F1 Whisper ниже (0,02–0,06 против 0,10–0,14), CTC выше (0,34 против 0,18–0,28). Возможные причины, не проверенные: другое определение границ (у нас у каждого слова две свои границы, у FA-Bench смежные слова делят одну), другие клипы и разбиение дикторов, faster-whisper int8 против их Whisper, разные версии MMS и MFA. Поэтому только порядок величины, без чисел «лучше/хуже FA-Bench».

## 5. Предлагаемые утверждения (требуют утверждения автором)

- **CLAIM-114 (кандидат).** On Buckeye test speakers, boundary F1 at 20 ms that charges missed and inserted words gives the same conclusions as MAE: known text beats Whisper text (0.710 vs 0.624), BRQE beats the constant offset in both scenarios (0.766 vs 0.707 and 0.677 vs 0.621), MFA beats CTC; each difference holds for all 20 speakers (exact Wilcoxon, Holm p < 0.001). Source: `reports/f1_20261123/f1_results.json`.
- **CLAIM-115 (кандидат).** Scored over all reference boundaries, scenario-B recall at 20 ms on Buckeye is 7.7 to 8.3 points below matched-word Acc@20 (about 11 % relative), so matched-word scores for recognized text are optimistic; for the known transcript the gap is 0.3 points.
- **CLAIM-116 (кандидат, качественное).** Our word-level F1 at 20 ms for MFA (0.68–0.71) and the system order MFA > CTC > Whisper timestamps agree with FA-Bench; absolute values for Whisper and CTC differ, with different boundary definitions and splits.

Его проверка корректности (Acc@20 и число сопоставленных против frozen) тоже прошла для всех 18 пар «корпус — режим».

Неоднозначности протокола, которые он отметил (ни одна не изменила числа):

2. Не определено «упавший клип»: принято — статус не `ok` в предсказаниях или в строках клипов.
3. Детали бутстрепа (один набор выборок для всех режимов, метод перцентилей) не заданы; совпадение полное.
4. F1 диктора при P + R = 0 не задана; принят 0.
5. Ничьи в тесте Уилкоксона не заданы.
6. В протоколе «20 дикторов», на TIMIT их 16.
7. F1_ctx: сопоставленное первое эталонное слово, перед которым в предсказании стоит вставка, не проходит проверку контекста.
8. Цена несопоставленных наследует округление frozen Acc@20 до двух знаков.
9. Поле `mean_difference_ms` в `f1_results.json` на самом деле в единицах F1 (имя унаследовано от общего `paired_test`); то же с `n_worse` — для F1 это число дикторов, у которых условие **лучше** базы.
