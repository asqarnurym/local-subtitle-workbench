## 1. Группы границ по положению и соседям

Каждая эталонная граница клипа относится ровно к одной группе. Своё слово — слово, которому принадлежит граница. Сосед — слово по другую сторону границы: для начала r-го слова это r−1, для конца — r+1. «Сопоставлено» означает, что слово вошло в пары Needleman–Wunsch.

- **Край** — начало первого слова клипа (B) или конец последнего (E):
  - M1B / M1E — своё слово сопоставлено;
  - M0B / M0E — не сопоставлено.
- **Внутренняя граница** (I):
  - M2I — сопоставлены и своё слово, и сосед;
  - M1I — сопоставлено ровно одно из двух;
  - M0I — ни одно.

На упавших клипах все слова несопоставлены.

Для каждой группы и режима:
- доля эталонных границ;
- recall@20 — доля границ группы, у которых своё слово сопоставлено и ошибка ≤ 20 мс;
- MAE по границам группы со своим сопоставленным словом.

Recall@20 в группах M0 по определению равен 0. В группе M1I часть границ может быть попаданием: своё слово сопоставлено, а сосед нет.

## 3. Знаковые ошибки и ошибка длительности

Для сопоставленных слов:
- знаковая ошибка начала e_s = t̂_s − t_s;
- знаковая ошибка конца e_e = t̂_e − t_e;
- ошибка длительности e_d = (t̂_e − t̂_s) − (t_e − t_s) = e_e − e_s, в мс.

Для каждого режима:
- средние e_s, e_e, e_d;
- средний |e_d|;
- MAE границ, для сравнения с |e_d|;
- интервалы бутстрепа по дикторам для средних e_s, e_e, e_d (среднее по всем словам выбранных дикторов).
