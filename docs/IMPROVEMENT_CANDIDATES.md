# Кандидаты улучшений: статья DG 2027 и общий план

Версия 13.11.2026. Только теоретический разбор. **Ничего не запускалось; эксперименты — только по отдельной просьбе автора.** Числа ниже — замороженные результаты проекта либо явно помеченные оценки. Ожидаемые выигрыши не проверены.

## 1. Правила для всех кандидатов

- **Где может быть выигрыш.** Каждая идея относится к одной из зон:
  - **A** — короткие фразы, известный текст: 17,0 мс (A2 + BRQE, Buckeye) при расхождении разметчиков 10–16 мс (CLAIM-011). Запас — единицы мс.
  - **B** — короткие фразы, текст Whisper: 27,7 мс (B2 + BRQE), покрытие 89,0%. Запас больше, и половина его — в покрытии.
  - **L** — длинные записи (S1b): сбои MFA растут с числом чанков (1,3–1,5% провальных чанков в A, 3,9–4,8% в B); ошибка около стыков.
  - **V** — видео: звено «звук ↔ изображение» (`RESEARCH_SCOPE.md` §6).
- **Разработка — только на 20 обучающих дикторах Buckeye** (CV, как у BRQE). Тестовые дикторы — один раз на выжившую идею, по протоколу, записанному до чисел. Оракульные расчёты на сохранённых тестовых предсказаниях допустимы только для отбраковки (верхняя граница), не для выбора параметров.
- **Замороженные результаты и утверждённые CLAIM не меняются.** Новая методика — отдельное подысследование.
- **Скорость и RTF не метрики оценки (D1).** Оптимизации записываются как инженерные свойства.

## 4. Отбраковано теоретически

| Идея | Почему |
|---|---|
| Нарезать MFA на маленькие окна вокруг каждого слова (последовательное сужение) | Внутри чанка MFA ищет глобальное выравнивание и не нуждается в начальном приближении; маленькие окна теряют контекст и статистику адаптации к диктору |
| CTC → MFA как начальное приближение на коротких фразах | По той же причине выигрыш ожидается нулевым. Полезная часть идеи — стыки (G-9) и слияние (G-4 после P-1) |
| Другой шаг кадра MFA (< 10 мс) | Модель обучена на 10 мс; округление (около 2,5 мс в среднем при равномерной ошибке ±5 мс) уже закрывает BRQE |
| «Просто другая спектрограмма» для MFA | MFA уже на MFCC с адаптацией; менять признаки = переобучать модель |
| Аудиовизуальное выравнивание по губам для границ слов | Нет открытых видео с ручными границами слов |
| Свой GMM-HMM или свой нейронный выравниватель с нуля | Не обгонит MFA; месяцы работы (обсуждение 09.11.2026) |
| Облачные VLM/LLM | Невоспроизводимо, мал научный вклад (`RESEARCH_SCOPE.md` §4(c)) |
