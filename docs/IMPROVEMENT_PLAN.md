# План доработки local-subtitle-workbench (статья 2 + статья AIML)

Версия: 27.10.2026. Основа: аудит репозитория (commit c7656b1), Индивидуальный план магистранта, литература 2026 г. (FA-Bench, FuseAlign, «Where Words Begin and End»).

Метрики оценки — только из Плана: **среднее отклонение границ от эталона (MAE, мс)** на уровне слов и фонем, с 95% CI, и **доля границ в пределах 20 мс (Acc@20ms)** как проверка цели «<20 мс». Сравнение методов (Base vs Proposed) — парный тест Уилкоксона с поправкой Холма. RTF, VRAM/RAM, MedAE, RMSE, Acc@50/100 не измеряются и не публикуются.

## 0. Принцип: эталонный пайплайн + изолированные подысследования

Обязательное ядро для научной работы — **один полный эталонный пайплайн без фолбеков и пропусков шагов**, проверенный на корпусах с **ручной** разметкой. Всё остальное (компромиссы, альтернативы, ML-модуль, устойчивость) — изолированные подысследования поверх ядра и замороженного бенчмарка. Их можно внедрять независимо друг от друга, в любом порядке, и каждое оформляется как дополнительный результат или уходит в бэклог.

```
ЯДРО (обязательно, фаза 1–3)          ПОДЫССЛЕДОВАНИЯ (независимы, фаза 4+)
VAD → Whisper → якорение (DTW/NW)     S1 дрейф на длинных записях
  → чанкинг → MFA → сшивка → экспорт  S2 устойчивость к темпу речи
Эталон: TIMIT-sample, Buckeye         S3 размер ASR-модели → точность границ
Base vs Proposed, сценарии A и B      S4 акцент (L2-ARCTIC, silver)
                                      S5 ML-модуль BRQE (курс AIML)
```

## 3. Фаза 3 — полный пайплайн и режимы

### 3.1. Proposed (эталонный пайплайн)
Silero-VAD → Whisper large-v3 (GPU) → якорение (E5) → чанкинг по паузам → MFA (батч) → глобальная монотонная сшивка → WebVTT / JSON-LD. Никаких фолбеков: сбой шага = ошибка, фиксируется.

### 3.2. Режимы бенчмарка (честные пары)

**Сценарий B — текста нет (основной реальный сценарий лекций):**
- B0 Base: Whisper word timestamps
- B1 Base: Whisper → MMS_FA (CTC), аналог WhisperX
- B2 **Proposed**: Whisper → якорение → MFA

**Сценарий A — текст лекции известен (скрипт, готовые субтитры):**
- A1 Base: MMS_FA (CTC) по эталонному тексту
- A2 **Proposed**: якорение → MFA по эталонному тексту

В сценарии B метрики считаются по совпавшим словам; доля совпавших слов (`num_matched/num_ref`) публикуется рядом, чтобы ошибки распознавания не прятались.

### 3.3. Выборка
TIMIT-sample: все 160. Buckeye: все 40 спикеров, разбиение по спикерам (тест — 20 спикеров; остальные — обучение ML-модуля). Буткстрэп CI по спикерам.

## 6. ML-модуль для курса AIML: BRQE

**Boundary Refinement & Quality Estimation** — собственная обучаемая модель, отключаемая (`--refiner none|brqe`), стоит после MFA.

**Вход:** окно лог-мел-спектрограммы ±100 мс вокруг каждой границы MFA + признаки контекста (тип фонем слева/справа, длительность, правдоподобие MFA, расхождение MFA и CTC, уверенность Whisper).

**Модель:** лёгкая 1D-CNN (или CNN+BiGRU), две головы:
1. **Регрессия поправки** Δt (мс) к границе MFA → уточнение ниже 10-мс сетки MFA.
2. **Классификация надёжности**: P(ошибка границы > 20 мс) → отбраковка / пометка для ручной проверки / маршрутизация.

**Данные:** Buckeye, разбиение по спикерам (train 20 / test 20), ручные границы — цель. TIMIT-sample — внешний тест без обучения. Обучение на CPU/RTX 3050 за минуты–часы.

**Оценка:** те же метрики Плана (MAE, Acc@20ms) для пайплайна с/без BRQE; для головы надёжности — ROC-AUC / PR-AUC и кривая «доля отбракованных слов → MAE оставшихся».

**Почему подходит:** классическая и проверенная идея (нейросетевое уточнение границ после HMM-выравнивания), в 2026 г. востребована (FuseAlign, «Where Words Begin» показывают выигрыш нейро-уточнения), реализуема на малых данных, прямо улучшает целевую метрику диссертации. Для диссертации — опциональная абляция; для курса AIML — основной вклад (своя модель, обучение, валидация, абляции).

**Риски:** без регистрации Buckeye обучающих ручных данных почти нет (TIMIT-sample — 160 высказываний). Обучать на MFA-silver нельзя — модель выучит MFA.
