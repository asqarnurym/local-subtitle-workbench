## P-1. Оракул «CTC + MFA»

**Вопрос.** Сколько максимум может дать любое объединение границ CTC и MFA?

- Пары режимов: (A1_ctc, A2_proposed), (A1_ctc, A2_brqe), (B1_whisper_ctc, B2_proposed), (B1_whisper_ctc, B2_brqe). Основной корпус — Buckeye (20 тестовых дикторов); TIMIT — вторичный.
- Общий набор: клипы, успешные в обоих режимах; внутри клипа — эталонные слова, сопоставленные в обоих режимах.
- На общем наборе считаются: MAE стороны MFA, MAE CTC, **оракул** — среднее min(|e_CTC|, |e_MFA|) по каждой границе, и **усреднение** — граница как среднее двух предсказаний (без параметров). Сообщается доля границ MFA, вошедших в общий набор.
- **Правило решения (до чисел).** Выигрыш оракула = MAE стороны MFA − MAE оракула (среднее по дикторам, Buckeye). Если для пар с BRQE он < 2 мс в обоих сценариях, объединение CTC и MFA (кандидат G-4) закрывается. Если ≥ 2 мс хотя бы в одном, G-4 остаётся кандидатом. Оракул оптимистичен: даже прохождение не означает достижимый выигрыш. Усреднение сообщается описательно, без теста.

## P-2. Детерминированный соперник BRQE: сдвиг к изменению спектра

**Вопрос.** Может ли простое правило без обучения уточнить границы MFA?

- **Признак.** Лог-мел-спектрограмма: 16 кГц, окно 25 мс (Ханн), шаг 2,5 мс, 40 полос 0–8000 Гц. Спектральный поток кадра — сумма по полосам положительных приращений лог-энергии относительно предыдущего кадра. Время значения потока — середина между центрами двух соседних кадров.
- **Правило.** Для каждого уникального времени границы клипа t ищется максимум потока в окне [t − W, t + W]; новая граница t + α·(t_пик − t). Если в окне нет кадров, граница не меняется. Монотонность: времена обрабатываются по порядку; если новое время не больше предыдущего нового плюс 1 мс, сохраняется исходное. Слово, у которого после сдвига начало ≥ конца, получает исходные границы.
- **Сетка (только обучающие дикторы).** W ∈ {10, 20, 30} мс, α ∈ {0,5; 1,0}; отдельно для A2 и B2. Выбирается конфигурация с наименьшим средним по 20 обучающим дикторам MAE слов.
- **Правило перехода к тесту (до чисел).** Тестовые дикторы используются, только если выигрыш выбранной конфигурации над MFA на обучающих дикторах ≥ 0,5 мс в данном сценарии. Иначе сценарий закрывается без теста.
- **Тест (один раз).** На 20 тестовых дикторах Buckeye выбранная конфигурация применяется к frozen A2_proposed / B2_proposed. Сравнения: сдвиг против MFA и сдвиг против MFA + BRQE (frozen A2_brqe / B2_brqe) в каждом прошедшем сценарии. Холм по всем выполненным тестам P-2.

## P-4. Предыдущие слои как детектор ошибок MFA

**Вопрос (идея автора).** Предсказывает ли расхождение CTC и MFA ошибку MFA, и дополняет ли оно голову надёжности BRQE?

- Buckeye, сценарии A и B. Слова базы — A2_proposed / B2_proposed, сопоставленные с эталоном. Метка — max(|e_начала|, |e_конца|) > 20 мс, как у головы надёжности (CLAIM-105).
- Оценки:
  1. BRQE — 1 − confidence соответствующего слова A2_brqe / B2_brqe;
  2. расхождение — max(|Δ начала|, |Δ конца|) между словом MFA и словом CTC (A1 / B1), сопоставленным с тем же эталонным словом;
  3. комбинация — среднее процентильных рангов оценок 1 и 2 (без параметров).
- Набор оценки — слова, где есть обе оценки. Сообщаются ROC-AUC и PR-AUC. Проверка: ROC-AUC BRQE на всех словах базы совпадает с frozen `quality_estimation` (0,756 / 0,749).
- **Правило интерпретации (до чисел).** Расхождение «дополняет BRQE», если 95% интервал бутстрепа по дикторам для AUC(комбинация) − AUC(BRQE) целиком выше нуля. Иначе — «не дополняет».
- **P-4b, длинные записи.** По `benchmark_utterances.json` прогонов S1b с якорями: для каждой длины число записей, где MFA (A2 / B2) провалился, а CTC (A1 / B1) выровнял. Только описание; подмена результата не рассматривается (правило «без фолбеков»).
